# Diabetes Regression – Machine Learning Project

## 📌 Project Overview
This project applies regression models to predict diabetes disease progression using clinical features from the `load_diabetes` dataset in scikit-learn.

## 🧠 Models Used
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## 📊 Evaluation Metrics
- RMSE
- R²

## ✅ Best Result
Gradient Boosting achieved the best performance:
- RMSE ≈ 53.18
- R² ≈ 0.466
